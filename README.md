# Vinheria Agnello

Sistema de cadastro e análise de vinhos artesanais desenvolvido para o Checkpoint 02. O programa permite cadastrar até cinco vinhos, valida o nome, a safra e a quantidade em estoque, identifica vinhos com estoque baixo, classifica os vinhos pela idade da safra e apresenta um resumo com o total cadastrado e a safra mais antiga.
